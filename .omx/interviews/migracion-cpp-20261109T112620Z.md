# Entrevista de migración de FusionForce a C++

1. Alcance. El usuario confirmó que entra todo el código.
2. Límite del alcance. Se comprobó si podrían quedar lanzadores o utilidades Python. El usuario exigió compilar, ejecutar y probar sin Python.
3. Dependencias instaladas. El usuario aceptó que ROS 2 incluya Python en el entorno si FusionForce prescinde de él.
4. Resultados. El usuario aceptó tolerancias justificadas por magnitud y exigió conservar formatos y decisiones observables.
5. Plataforma. El usuario eligió Linux y aceptó WSL2 desde Windows.

Perfil estándar, cinco rondas, umbral del 20 %, ambigüedad final estimada del 12 %. Se comprobó el límite de «todo el código» con el caso de los lanzadores y después con la instalación de ROS 2.
